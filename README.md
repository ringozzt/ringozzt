I care about **where software meets judgment** — the thin layer where agents, products, and humans actually collaborate.

Most of my work lives in three currents:

| | |
|---|---|
| **Agent systems** | Local-first agent runtimes, multi-agent collaboration, tool-use loops, and the infrastructure that makes long-running AI work trustworthy. |
| **Human ↔ agent interfaces** | Native desktop utilities, browser feedback channels, and UX that turns vague intent into precise machine action — without a wall of prompts. |
| **Product engineering at scale** | Full-stack delivery across TypeScript and Go: monorepos, BFF/gateway patterns, observability, and shipping under real production constraints. |

> Day job is large-scale product engineering at **ByteDance**. Public writing and open source stay intentionally abstract — the interesting details are usually the ones that shouldn't leave the building.
